# Сервис автоматического краткого пересказа текста

Сервис принимает на вход текст или файл в форматах `*.txt`, `*.docx`, `*.md`, `*.pdf` (с возможностью извлечения текста), `*.fb2`, `*.epub` и формирует на его основе краткий пересказ текста и основные разделы с примерным временем чтения в соответсвии с указанием пользователя.

Основные пользователи:

- пользователи

Основные функции:

- Ввод текста/файлов, примерное желаемое время чтения пересказа
- Проверка файла на повреждения
- Генерация краткого пересказа текста
- Отображение результата/ошибки работы системы

## Ограничения

Поддерживаются только следующие форматы данных:

- `*.txt`
- `*.docx`
- `*.md`
- `*.pdf` (с возможностью извлечения текста)
- `*.fb2`
- `*.epub`

Сервис извлекает и анализирует только доступные UNICODE символы из файла/поля ввода, изображения и диаграммы анализу не подвергаются.

Поддерживаемые языки:

- Русский
- English (USA)
