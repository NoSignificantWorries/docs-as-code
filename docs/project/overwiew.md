# Сервис автоматического краткого пересказа текста

Сервис принимает на вход текст или файл в форматах `*.txt`, `*.docx`, `*.md`, `*.pdf` (с возможностью извлечения текста) и формирует на его основе краткий пересказ текста и основные разделы с примерным временем чтения в соответсвии с указанием пользователя.

Основные пользователи:
- пользователи

Основные функции:
- Ввод текста/файлов, примерное желаемое время чтения пересказа
- Проверка файла на повреждения
- Генерация краткого пересказа текста
- Отображение результата/ошибки работы системы
