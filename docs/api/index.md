# API

Ключевые API для взаимодействия с TexSum.

## Основные операции

- `POST /summaries` - сгенерировать краткий пересказ текста
- `GET /summaries/{summary_id}` - получить статус и результат генерации
- `GET /files/validate` - валидация загруженного файла

## Спецификация

Полное описание API находится в файле `openapi.yaml`.
