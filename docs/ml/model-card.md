NLLB Summarization Model (TradeNewsSum)

**Источник:**

Hugging Face: [lyutovad/nllb-tradenewssumj](https://huggingface.co/lyutovad/nllb-tradenewssum)

**Автор / организация:**

Автор модели - Daria Lyutova (пользователь lyutovad на Hugging Face). В связанной научной публикации указана как представитель Всероссийской академии внешней торговли и Университета ИТМО.

**Задача модели:**

Абстрактивная суммаризация - генерация кратких, информативных пересказов новостных текстов.

**Язык:**

- Русский
- Английский

**Лицензия**

## Использование в проекте

Модель используется для генерации краткого пересказа входного текста в соответствии с заданой длиной и исходным языком.

Модели в чистом виде требуется дообучение, так как изначально она обучена только на пересказ новостных статей.

Введённый пользователем текст проходит валидацию (из файлов текст предварительно извлекается) и передаётся модели. Формируется запрос с указанием длины последовательности и языка генерации. Модель генерирует краткий пересказ текста и возвращает пользователю.

## Входные данные

Модель получает на вход текстовую строку на русском или английском языке. Входной текст токенизируется с указанием языкового кода (rus_Latn или eng_Latn), максимальная длина входной последовательности - 1024 токена.

## Выходные данные

Модель возвращает сгенерированный текст краткого пересказа на том же языке, что и входной текст.

## Метрики качества

Авторами модели приведены следующие метрики на тестовой части датасета TradeNewsSum :

|Язык|ROUGE-1|ROUGE-2|ROUGE-L|ROUGE-Lsum|METEOR|BERTScore-F1|NER-F1|
|---|---|---|---|---|---|---|---|
|ru|0.5948|0.4954|0.3446|0.4898|0.4900|0.9528|0.704|
|en|0.5225|0.5807|0.4400|0.5178|0.5178|0.9300|0.618|

Расшифровка метрик:
- ROUGE измеряет n-граммное пересечение
- METEOR учитывает синонимы и стемминг
- BERTScore оценивает семантическую близость через контекстные эмбеддинги
- NER-F1 измеряет сохранение именованных сущностей в пересказе 

## Ограничения

- Модель обучена на домене новостей внешней торговли и не предназначена для общей суммаризации текстов за пределами этого домена.
- Модель поддерживает только русский и английский языки, работа с другими языками не предусмотрена.

### Потенциальные проблемы для нашего проекта

- Не предусмотрен способ указания размера генерации.
- Возможны галлюцинации для текста в научном стиле или с обилием жаргона.

## Не рекомендуется использовать

- Использование модели за пределами домена внешней торговли.
- Ипользование модели для неподдерживаемого языка.
- Использование модели вне рамок суммаризации заданного текста.
